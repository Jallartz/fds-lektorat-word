Lektorat

Texte gegen die Satzanweisung prüfen – live in WoodWing, als PDF-Checker und in Microsoft Word.

Anmeldung

Bitte mit deinem FDS-Konto anmelden.

Chrome-Plugin

Das Plugin markiert in WoodWing und in PDFs alle Stellen, die gegen die Schreibweisen des gewählten Auftrags verstoßen.

Im Chrome Web Store installieren

Aktuelle Version: … · Installierte Version: in Chrome unter chrome://extensions bei „FDS Lektorat“.

So geht's (1 Minute)
  1. Oben auf „Im Chrome Web Store installieren“ klicken → „Hinzufügen“. Updates kommen danach automatisch.
  2. Puzzle-Symbol in der Chrome-Leiste → „FDS Lektorat“ anpinnen.
  3. Plugin-Symbol klicken → mit deinem FDS-Konto anmelden (dieselben Daten wie hier).
  4. Artikel in WoodWing öffnen → im Plugin die Satzanweisung (Kürzel) wählen – die Fehler werden sofort rot unterstrichen.
Installation per ZIP (falls der Store nicht geht)
  1. ZIP herunterladen und entpacken (Doppelklick). Den Ordner FDS-Lektorat nach „Dokumente“ verschieben – nicht im Download-Ordner lassen. Chrome lädt das Plugin dauerhaft aus diesem Ordner: wird er gelöscht, verschoben oder umbenannt, verschwindet das Plugin aus Chrome.
  2. In Chrome chrome://extensions öffnen und oben rechts den Entwicklermodus einschalten.
  3. „Entpackte Erweiterung laden“ klicken und den entpackten Ordner wählen.
  4. Puzzle-Symbol → „FDS Lektorat“ anpinnen → anmelden → Satzanweisung wählen.
  5. Update: neue ZIP entpacken, den Inhalt in den bestehenden Ordner „Dokumente/FDS-Lektorat“ kopieren (ersetzen), in chrome://extensions bei „FDS Lektorat“ auf ↻ klicken und offene WoodWing-Tabs neu laden (F5). Keinen zweiten Ordner anlegen.

Einstellungen (Darstellung der Markierungen, Sprache, Live-Prüfung): im Plugin auf das Zahnrad klicken. PDF-Checker: im Plugin „PDF prüfen“ → Satzanweisung wählen → PDF hineinziehen → kommentiertes PDF herunterladen. Datenschutz

Word-Add-in

Dieselbe Prüfung direkt in Microsoft Word: Satzanweisung wählen, Dokument prüfen – Fehler werden im Dokument farbig unterstrichen und lassen sich per Klick ersetzen. Dazu KI-Prüfung, Umschreiben und die White-/Blacklist der Satzanweisung.

So geht's – Word unter Windows
  1. Oben die Datei FDS-Lektorat-Word.xml herunterladen und z. B. unter „Dokumente“ ablegen.
  2. Word öffnen → Registerkarte Start → Add-Ins (bzw. Einfügen → Add-Ins abrufen) → Meine Add-Ins → oben rechts „Mein Add-In hochladen“.
  3. Die XML-Datei auswählen → Hochladen. In der Registerkarte Start erscheint ganz rechts die Schaltfläche „Lektorat“.
  4. „Lektorat“ klicken → mit deinem FDS-Konto anmelden (dieselben Daten wie hier) → Satzanweisung wählen → „Dokument prüfen“.
Word auf dem Mac
  1. Word schließen. Im Finder Gehe zu → Gehe zum Ordner… (⇧⌘G) und eingeben: ~/Library/Containers/com.microsoft.Word/Data/Documents/wef – gibt es den Ordner wef nicht, ihn anlegen.
  2. Die Datei FDS-Lektorat-Word.xml in diesen Ordner kopieren.
  3. Word öffnen → Start → Add-Ins (bzw. Einfügen → Meine Add-Ins) → unter „Entwickler-Add-Ins“ FDS Lektorat wählen.
Word im Browser (Office 365)
  1. Dokument in Word im Browser öffnen → Start → Add-Ins → Weitere Add-Ins → Meine Add-Ins → „Mein Add-In hochladen“ → XML-Datei wählen.

Updates kommen automatisch – die Datei muss nur einmal installiert werden. Für alle Mitarbeiter auf einmal kann ein Microsoft-365-Administrator die Datei im Microsoft 365 Admin Center → Einstellungen → Integrierte Apps → Benutzerdefinierte Apps hochladen verteilen; dann erscheint „Lektorat“ bei allen automatisch.
